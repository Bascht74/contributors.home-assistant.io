Each guide covers one task around a release. Most of them matter to anyone who opens a pull request, not only to the people who run the release.

- [Release notes and the release party](/releases/guides/release-notes/): how the monthly release notes come together, and how you can help.
- [Document a backward-incompatible change](/releases/guides/backward-incompatible-changes/): tell users what breaks, how to fix it, and why.
- [Deprecate something](/releases/guides/deprecations/): the deprecation policy, and how deprecations reach the release notes.
- [Get a fix into a patch release](/releases/guides/patch-releases/): how a bug fix reaches the beta and the patch releases.
