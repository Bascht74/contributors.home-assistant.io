Home Assistant uses two layers of color tokens:

1. **Core tokens** are the raw palettes below. Do not use them directly in components.
2. **Semantic tokens** describe a purpose, like `--ha-color-text-primary` or `--ha-color-fill-primary-loud-resting`. They point to core tokens, and switch automatically in dark mode.

> [!TIP]
> Reach for a semantic token first. If none fits, that is a conversation for the design team, not a reason to use a core token.
