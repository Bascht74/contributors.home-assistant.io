The `dev` branch has the newest code, and nightly builds are made from it. What was released lives on another branch, like `master` in Home Assistant Core. Some repositories develop on `main` instead, like the Supervisor and the Android app.

The documentation on home-assistant.io works differently: `current` is what readers see now, and `next` collects the documentation for the next release.
