Home Assistant has its own words, and some of them go by another name in the code than in the UI. Here, every term has one meaning, and one page that says how it goes by everywhere: in the code, in the UI, and what it used to be called.

Use these terms the way they are defined here, in code, UI text, and documentation. In the docs on this site, terms link to their definition by themselves, the first time a page uses them: point at a word with a dotted line to see what it means.

Missing a term, or found one that could be clearer? Every term is a page in `src/content/docs/glossary/`: edit it, or add a new one.
