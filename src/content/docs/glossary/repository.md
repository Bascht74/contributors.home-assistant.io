Think of a repository as the folder of a project, with a memory. Every part of Home Assistant has its own: Home Assistant Core is in `home-assistant/core`, the documentation in `home-assistant/home-assistant.io`, and the interface in `home-assistant/frontend`. Each repository has its own issues, pull requests, and maintainers.

New to GitHub? [Use GitHub, without being a developer](/start/github/) explains the words you meet there.
