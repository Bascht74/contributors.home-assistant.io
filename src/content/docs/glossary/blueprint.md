The blanks are inputs, and each input can have a [selector](/glossary/selector/), so the UI can show the right control for it.

Users import blueprints from a link, like a forum topic or a file on GitHub, not from the [Marketplace](/glossary/marketplace/). To write and share one, see [blueprints](/marketplace/guides/blueprints/) in the Marketplace area.
