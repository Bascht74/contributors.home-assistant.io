A dashboard has one or more [views](/glossary/view/), and each view holds [cards](/glossary/card/). Home Assistant can build a dashboard by itself, with a [strategy](/glossary/strategy/).

Dashboards used to be called Lovelace, after their code name, until Home Assistant 2022.4. The code still uses it, like the `lovelace` panel and the `hui-` prefix of dashboard elements. In text, say dashboard.
