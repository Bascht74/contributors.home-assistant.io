The last number of the version counts the patch releases: 2026.10.1 is the first one after 2026.10.0. Fixes are merged into the `dev` branch first, and then picked for the next patch release. Each patch release gets its own section in the release notes of that month. See [Get a fix into a patch release](/releases/guides/patch-releases/).
