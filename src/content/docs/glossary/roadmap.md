The roadmap is not a list of features with dates. It is a set of [opportunities](/glossary/opportunity/), each a problem worth solving, managed by the product team of the foundation. Feature requests from the community feed into it, and each opportunity links to one of the foundation's goals. See [from idea to release](/roadmap/how-it-works/).
