The Marketplace is the `marketplace` integration in core, with its panel under **Settings** > **Marketplace**. It is [HACS](/glossary/hacs/), brought into Home Assistant: it shows the same catalog, and reads the same `hacs.json` file from each repository.

What it installs is made and supported by the community, not by the Home Assistant project. [Blueprints](/glossary/blueprint/) are not in the Marketplace: users import them from a link. The [Marketplace area](/marketplace/) explains how to publish for it.
