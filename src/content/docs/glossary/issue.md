Each repository has its own issues. In Home Assistant, issues are for problems: a bug, or a page of the documentation that is wrong. Feature ideas go to the [feature request discussions](https://github.com/orgs/home-assistant/discussions), and support questions to the [community forum](https://community.home-assistant.io/). See [where we talk](/start/where-we-talk/).

Not the same as a repair issue, which Home Assistant shows to its users. That is a [repair](/glossary/repair/).
