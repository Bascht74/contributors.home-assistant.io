The easiest way to start helping is to answer a question. You do not need to be an expert. If you got something working in your own home, you can help someone else get there too.

## 1. Create a forum account

Go to the [community forum](https://community.home-assistant.io/) and sign up for a free account.

## 2. Read the forum guidelines

The forum has a short guide on [how to ask a good question](https://community.home-assistant.io/t/how-to-help-us-help-you-or-how-to-ask-a-good-question/114371). It is written for people asking for help, but reading it tells you what a good question looks like, and what to ask for when a question is missing details.

## 3. Find a question you can answer

Open the [latest topics](https://community.home-assistant.io/latest) and look for a question without replies, in an area you know. Your own setup is the best guide: if you use Zigbee, look for Zigbee questions. If you write a lot of automations, look in the configuration category.

Do not worry if you cannot find something right away. Read a few topics, and come back tomorrow. New questions arrive all day.

## 4. Write your answer

- Answer the question that was asked. If you need more information first, ask for it, like the Home Assistant version, the installation type, or the log messages.
- Share configuration as text in a code block, not as a screenshot. In YAML, the spacing matters.
- Link to the documentation where it helps, so the person learns where to look next time.
- Be honest when you are not sure. "This worked for me, but I have not tried it with your device" is a perfectly good answer.

> [!IMPORTANT]
> Do not paste answers generated by ChatGPT or similar tools. The forum guidelines ask for this explicitly: those answers often look right, but are incomplete, misleading, or just wrong. Answer from your own experience.

## 5. Follow up

Check back on the topic. If your answer helped, the person who asked can mark it as the solution, so the next person with the same problem finds it right away. If it did not help, keep going, or let someone else pick it up. Both are fine.

## What is next

- Read [Welcome newcomers](/community/guides/welcome-newcomers/). A lot of questions come from people who just installed Home Assistant.
- Join the [Discord server](https://www.home-assistant.io/join-chat) for quicker, live conversations.
- Learned something while answering? The documentation could probably use it too. See [Writing docs](/writing/).
