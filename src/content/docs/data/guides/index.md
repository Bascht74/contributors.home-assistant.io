Each guide covers one task. The first three need no code, only some curiosity. The last one is for integration developers.

- [Use the public data](/data/guides/public-data/): download the analytics data sets, and build your own charts.
- [Explore your own data](/data/guides/explore-your-data/): connect JupyterLab to the database of your Home Assistant, and run your first report.
- [Query the database](/data/guides/query-the-database/): example SQL queries for states, events, and context.
- [Analytics in your integration](/data/guides/integration-analytics/): how your integration shows up in analytics, and how to keep devices or entities out.
